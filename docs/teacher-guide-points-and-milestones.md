# Teacher Guide: Stars, Sessions, and Milestones

On-task Otter turns on-task classroom time into a shared class goal. The class completes on-task sessions, earns stars, and uses stars to decorate the otter's house or dress up the otter.

This guide explains how to use the system and what the class can work toward.

## Set Up an On-task Session

1. Open **Session settings** using the gear button on the On-task Session card.
2. Choose a session length: **5, 10, 15, or 20 minutes**.
3. Choose the kind of activity:
   - **Independent work:** very quiet
   - **Partner work:** moderate voices
   - **Presentation:** one clear speaker
4. If you want to use the noise meter, select **Microphone** at the top of the page once to choose your microphone and calibrate it for your room. Allow microphone access when asked. This setup is shared by every session preset and every class. The timer can still be used without the microphone.
5. Select **Start session** when the class is ready.

The timer can be paused and continued. If the noise meter reaches the "Too loud" level, the timer pauses so the class can reset. Select **Start session** again when the class is ready to continue.

Use **Reset** if you want to return the timer to the beginning. A reset or unfinished session does not earn stars and does not count as a completed session.

## How the Class Earns Stars

By default, the class earns **one star for every minute in a completed session**. To change the rate, open **Settings** (the gear in the bottom-right corner of the Configure screen) and set **Stars per minute** anywhere from 1 to 10. Every class earns at the same rate, and changing it only affects sessions finished from then on.

At the default rate:

| Session length | Stars earned |
| --- | ---: |
| 5 minutes | 5 stars |
| 10 minutes | 10 stars |
| 15 minutes | 15 stars |
| 20 minutes | 20 stars |

Stars are added only when the timer reaches zero. Pausing does not reduce the reward, as long as the class eventually finishes the session.

The Class Progress card shows two star totals:

- **Total stars earned** is the full number of stars the class has earned over time.
- **Available now** is the number of unspent stars the class can currently use.

Buying a reward lowers the available stars, but it does not lower the total stars earned.

## How Sessions Are Counted

One session is counted each time an on-task timer reaches zero. Every completed session counts as **one session**, whether it lasted 5, 10, 15, or 20 minutes.

For example, completing one 5-minute session and one 20-minute session gives the class:

- **2 completed sessions**
- **25 on-task minutes**
- **25 stars earned**

Only completed sessions count toward opening new rooms. Paused, reset, or unfinished sessions do not count.

The app shows the most recent five sessions on the Class Progress card. It remembers up to the 20 most recent completed sessions on the same device and browser.

## What Stars Can Buy

The class can spend available stars in two ways. Select **Decorate room** to buy house pieces, or select **Costume mode** to unlock accessories.

The otter wears one hat and one pair of glasses at a time. In **Costume mode**, select the otter's hat or glasses spot to see every choice; selecting one tries it on before you buy it.

### House Decorations

House decorations become more expensive as the class moves through the house, from **15 stars** for the first decoration to **325 stars** for the final one. A purchased decoration is placed in its room and cannot be purchased again.

Some decorations are part of milestones. Buying all the listed pieces for the current milestone completes it and moves the class to the next milestone.

## Rooms

Every room in the otter's house is open from the start. Select the house button in the top-right corner of the room to move the otter to any room.

## Milestones in Order

The Class Progress card follows the milestones in the order below and shows the first milestone that still has an uncollected piece. To finish a milestone, buy every listed decoration. The class may buy a piece from a later milestone early; that piece will already count when the class reaches that milestone.

There is no extra star prize for completing a milestone. The reward is seeing the completed themed space in the otter's house and moving on to the next class goal.

## Helpful Classroom Routine

1. Tell students the session length and the milestone piece they are working toward.
2. Choose the activity type so the noise goal matches the task.
3. Start the timer and use the noise meter as a neutral visual reminder.
4. Celebrate when the timer finishes and review the stars earned.
5. Let the class save stars or choose a reward together.

The app remembers progress on the same device and browser. For consistent class progress, use the same classroom computer and browser each time.

## Several Classes

If you teach more than one class, each class can have its own otter progress.

- Select the class name beside the On-task Otter logo to switch classes. The timer starts fresh when you switch.
- Select **Edit classes** in that menu to add, rename, or delete a class.
- Each class keeps its own **stars**, completed sessions, otter name, otter accessories, room decorations, and the room the otter is in.
- Session presets and the timer and noise settings are shared by every class.
- **Save Classroom Configuration** downloads one file with every class in it. Restoring that file brings back all of the classes.
